### 결과물

n8n 워크플로우로 매일 아침 AI 뉴스를 자동 수집해서 카카오톡 채널로 보내주는 봇을 만들었다. RSS 3개 소스에서 기사를 가져오고, Claude API로 한국어 3줄 요약을 생성한 뒤, 카카오톡 알림톡으로 발송하는 파이프라인.

- 배포: n8n Cloud에서 운영 중 (하루 1회 오전 8시 자동 실행)
- 기술 스택: n8n + Claude API + 카카오톡 비즈메시지 API

### 만든 과정 및 삽질

- RSS 파싱은 n8n 기본 노드로 쉽게 됐는데, 중복 기사 필터링이 문제였음. 제목 유사도로 비교하려다가 결국 URL 해시로 간단하게 해결
- Claude API 호출 시 토큰 비용이 걱정됐는데, 기사 원문 대신 첫 500자만 넣어도 요약 품질이 충분했음. 하루 3건 기준 월 $2 이하
- 카카오톡 비즈메시지 API 연동이 가장 삽질이 심했음. 템플릿 검수에만 3일 걸림. "변수 위치가 문장 중간에 오면 반려"라는 규칙을 몰라서 2번 반려당함
- 최종적으로 고정 텍스트 + 변수 블록 분리 구조로 템플릿 통과

### 인사이트

- n8n은 "코드를 몰라도 자동화를 만들 수 있다"가 아니라, "코드를 알면 10배 빠르게 자동화를 만들 수 있다"에 가까움
- API 비용은 입력 데이터 크기를 줄이는 것만으로도 극적으로 절감 가능. 전체 기사 vs 첫 500자 → 비용 차이 5배
- 카카오톡 비즈메시지는 자유도가 낮지만, 도달률이 이메일이나 슬랙보다 압도적으로 높음 (팀 내 열람률 95%)

### 다시 한다면?

- 뉴스 소스를 RSS 대신 X(트위터) 리스트로 바꾸면 더 실시간성 있는 정보를 잡을 수 있을 듯
- 요약 결과에 "관련도 점수"를 붙여서, 팀 관심사와 매칭률이 높은 기사만 보내는 필터 추가하고 싶음

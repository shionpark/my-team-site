### 결과물

Claude Code 슬래시 명령어 4개를 만들어서 팀 운영을 자동화했다. 매주 회의 끝나고 `/analyze 1` 한 번이면 분석 리포트 + 멤버 프로필 + 현황표가 한꺼번에 갱신된다. 배포까지 30분 안에 끝나는 구조를 완성.

- 데모: 실제 팀 vault에서 라이브로 시연
- 기술 스택: Obsidian + Claude Code + Astro + Vercel

### 만든 과정 및 삽질
 
- 처음에는 ChatGPT에 매주 수동으로 과제 내용을 붙여넣고 요약을 뽑았는데, 복사-붙여넣기만 매번 20분 이상 걸림
- Claude Code의 슬래시 명령어를 알게 되고 `.claude/commands/` 폴더에 프롬프트를 마크다운으로 넣으면 된다는 걸 깨달음
- 첫 번째 문제: 분석 결과가 매번 형식이 달랐음 → 프롬프트에 마크다운 템플릿을 명시해서 해결
- 두 번째 문제: 멤버 닉네임이 분석 보고서에 그대로 노출 → "닉네임 직접 언급 금지" 규칙을 프롬프트에 추가
- 세 번째 문제: 2-repo 구조에서 비공개 폴더가 공개 사이트로 넘어갈 뻔함 → sync-content.sh에 화이트리스트 방식 적용

### 인사이트

- Claude Code 슬래시 명령어는 "자연어 프롬프트를 파일로 저장하는 것"이라 진입장벽이 매우 낮다. 코딩 없이도 팀 자동화가 가능하다는 점이 놀라웠음
- 공개/비공개 분리는 도구 수준이 아니라 아키텍처 수준에서 해결해야 실수를 구조적으로 방지할 수 있다
- 운영 시스템은 "멤버가 한 가지만 하면 나머지는 자동으로 굴러가야" 지속 가능하다

# 봇 인사이트

> 이 파일은 `/analyze N` 실행 시 AI가 인사이트를 누적 추가합니다.

## 프로젝트 아이디어

### Week 01

1. **뉴스→리뷰 통합 개발 어시스턴트**: Jay의 뉴스 수집 파이프라인 + Luna의 코드 리뷰 봇을 결합. 매일 아침 AI/ML 관련 보안 취약점 뉴스를 수집하고, 해당 패턴이 팀 코드베이스에 존재하는지 자동 스캔하는 "선제적 보안 리뷰 봇".
2. **브랜딩 → 홈페이지 자동 생성 파이프라인**: Haru의 AI 브랜딩 워크플로우 + Alex의 Astro 배포 구조를 결합. 브랜드 가이드라인 마크다운에서 Astro 테마 변수(컬러 토큰, 타이포 설정)를 자동 추출하여 홈페이지 디자인을 원클릭 갱신.
3. **팀 학습 로그 자동 큐레이션**: 4명의 주간 과제에서 키워드를 추출하고, 관련 아티클/강의를 자동 추천하는 "팀 맞춤 학습 뉴스레터". n8n + Claude API + 이메일/슬랙 발송.

## 이렇게 하면 더 좋겠다

### Week 01

1. **과제 템플릿에 "기술 스택 태그" 필드 추가**: 현재 과제에 기술 스택이 본문에만 흩어져 있어 자동 분류가 어려움. frontmatter에 `tech_stack: [n8n, Claude API]` 같은 필드를 추가하면 스킬 매칭, 멤버 간 시너지 탐색이 자동화됨.
2. **"삽질 로그"를 별도 파일로 분리**: 모든 멤버가 가장 풍부하게 쓴 섹션이 "삽질" 부분. 이를 `02_skill_insight/`에 독립 인사이트로 분리하면 재사용 가능한 지식 자산이 됨. (예: "카카오톡 비즈메시지 템플릿 검수 통과 가이드")
3. **결과물 데모 링크 표준화**: 일부는 라이브 시연, 일부는 스크린샷 없음. 과제 템플릿에 `demo_url` 또는 `screenshot` 필드를 넣으면 갤러리 페이지 자동 생성에 활용 가능.

## 아무도 시도하지 않은 영역

### Week 01

- **RAG(검색 증강 생성)**: 팀 vault의 과제·인사이트를 벡터 DB에 넣고 "우리 팀이 이전에 비슷한 걸 한 적 있나?"를 검색하는 시스템. 멤버가 늘고 주차가 쌓일수록 가치가 커지는 영역.
- **음성/영상 AI 활용**: Whisper로 회의 녹음 자동 전사, 영상 편집 자동화 등. 4명 모두 텍스트 기반 파이프라인에 집중했는데, 멀티모달 입력으로 확장하면 회의록 자동화 같은 즉시 쓸모 있는 도구가 나올 수 있음.
- **데이터 분석/시각화 자동화**: CSV나 DB 데이터를 Claude에 넣고 인사이트를 추출하거나 차트를 자동 생성하는 파이프라인. 비개발 직군(마케팅, 영업)과 협업할 때 바로 활용 가능한 영역.

## 자유 생각

### Week 01

첫 주치고 놀라운 건, 4명 모두 "한 번 쓰고 버리는 결과물"이 아니라 "반복 실행 가능한 시스템"을 만들었다는 점이다. 뉴스 봇은 매일 돌아가고, 코드 리뷰 봇은 PR마다 작동하고, 분석 명령어는 매주 실행된다. 이건 "AI를 써봤다"가 아니라 "AI를 운영하기 시작했다"에 가깝다.

흥미로운 패턴 하나 — 삽질의 원인이 대부분 AI 자체가 아니라 "AI와 연결되는 외부 시스템의 제약"이었다. 카카오톡 템플릿 검수, GitHub API rate limit, Figma 플러그인 호환성. AI 역량을 키우는 것 못지않게, 연동 대상의 제약 조건을 빠르게 파악하는 능력이 실전에서는 더 중요할 수 있다.

# 스킬 제안

> 이 파일은 `/analyze N` 실행 시 AI가 제안을 누적 추가합니다. 직접 편집해도 됩니다.

## 제안 목록

### #1. 팀 뉴스 큐레이션 파이프라인 스킬

- **유형**: Claude Code 스킬
- **난이도**: 중급
- **관련 개념**: RSS 파싱, Claude API 요약, 메시징 API 연동
- **설명**: 여러 멤버가 AI 뉴스 수집-요약-발송 파이프라인에 관심을 보였다. RSS/X 소스에서 기사를 수집하고, Claude API로 한국어 3줄 요약을 생성한 뒤, Slack이나 카카오톡으로 발송하는 스킬. 입력 데이터 크기를 줄여 토큰 비용을 절감하는 패턴도 포함.
- **추천 멤버**: Jay (n8n 경험), Alex (슬래시 명령어 설계 경험)
- **참고**: [[Week_01_Jay_submit]]

### #2. PR 리뷰 자동화 Claude Code 스킬

- **유형**: Claude Code 스킬
- **난이도**: 중급
- **관련 개념**: GitHub Actions, Claude API, diff 분석, 오탐 제어
- **설명**: PR이 올라오면 diff를 파일별로 분석하고 보안 취약점, 성능 이슈, 스타일 위반을 잡아 종합 코멘트를 남기는 스킬. "확실하지 않으면 지적하지 마라" 프롬프트로 오탐률 60% 감소한 패턴 적용. `.cursorrules`와 프롬프트 규칙 통일로 로컬-CI 일관성 확보.
- **추천 멤버**: Luna (GitHub Actions 경험), Jay (API 비용 최적화 경험)
- **참고**: [[Week_01_Luna_submit]]

### #3. AI 브랜딩 키트 생성기

- **유형**: CLI 도구
- **난이도**: 초급
- **관련 개념**: Midjourney 프롬프트 생성, Claude 가이드라인 작성, 컬러 팔레트 추출
- **설명**: 브랜드명과 컨셉 키워드를 입력하면 Midjourney 프롬프트 5종 + 브랜드 가이드라인(컬러, 타이포, 톤앤매너) 마크다운을 자동 생성하는 도구. Figma Variables 연동까지 확장 가능.
- **추천 멤버**: Haru (브랜딩 워크플로우 경험), Alex (마크다운 자동화 경험)
- **참고**: [[Week_01_Haru_submit]]

### #4. Obsidian Vault 자동 분석 대시보드 플러그인

- **유형**: Obsidian 플러그인
- **난이도**: 고급
- **관련 개념**: Obsidian API, Dataview, frontmatter 파싱, 시각화
- **설명**: vault 내 과제 제출 현황, 멤버별 활동 트렌드, 키워드 빈도를 자동으로 대시보드로 시각화하는 플러그인. 현재 `/analyze`가 마크다운 파일로 생성하는 현황표를 실시간 인터랙티브 뷰로 전환. Dataview 쿼리 + Chart.js 조합.
- **추천 멤버**: Alex (vault 구조 설계 경험), Luna (자동화 파이프라인 경험)
- **참고**: [[Week_01_Alex_submit]]
